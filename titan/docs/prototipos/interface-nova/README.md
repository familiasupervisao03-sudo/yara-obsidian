# Nova interface do TITAN (aplicada: tema Vidro, em src/theme/vidro.css)

Baseada em 3 referências que o dono mandou: orbe de vidro + cartões (celular), painel de cartões
(notebook/TV) e chat com balões + tela "Estou ouvindo".

- `index.html` — simulação animada (abra no navegador).
- `exemplo-celular.png` — Início, Conversa e Voz (azul).
- `exemplo-roxo.png` — Início na cor roxa.
- `exemplo-notebook.png` — painel do notebook e da TV.

Aplicado em 21/11/26: as duas cores trocáveis em Sistema → Aparência (azul é o padrão); barra de baixo
com 5 botões (Início · Conversa · orbe Falar · Notícias · Você, que junta Memória e Sistema); no modo leve
sem vidro embaçado, brilho nem animação.
